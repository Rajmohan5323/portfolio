## ✨ Features

- 🌍 Interactive 3D Skills Sphere built with Three.js and React Three Fiber
- ⌨️ Animated typing effect for dynamic role titles
- 🌙 Dark & Light mode with persistent theme support
- 🎨 Modern warm amber UI with WCAG AA accessibility compliance
- ✨ Interactive cursor glow and particle effects
- 📬 Contact form powered by the Resend API
- 📊 Vercel Analytics integration for visitor insights
- ⚡ Vercel Speed Insights for real-user performance monitoring
- 🔍 SEO optimized with JSON-LD, Open Graph, dynamic OG image, sitemap, and robots.txt
- ♿ Accessibility features including skip-to-content navigation, semantic HTML, and focus-visible support
- 📱 Fully responsive across desktop, tablet, and mobile devices

## 🚀 Getting Started

### Prerequisites

- Node.js 15 or later
- npm, yarn, or pnpm

### Clone the Repository

```bash
git clone https://github.com/Rajmohan5323/portfolio.git

cd portfolio
```

### Install Dependencies

```bash
npm install --legacy-peer-deps
```

### Configure Environment Variables

Create a `.env.local` file.

```env
RESEND_API_KEY=re_your_api_key_here
CONTACT_EMAIL=your_email@example.com
```

### Start Development Server

```bash
npm run dev
```

### Visit:

```
http://localhost:3000
```

### Build for Production

```bash
npm run build
npm start
```
